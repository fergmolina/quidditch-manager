# Game data

All game content lives here as JSON. The full design rationale is in `docs/design/09-data-model.md`; this file is the practical reference for anyone editing or adding data.

- **Keys** are English `snake_case`. Don't rename them. The loader (`src/sim/sim_loader.gd`) and the world generator read them by name.
- **Player-facing text** normally comes from `locale/strings.csv`, not from these files. Names inside the data are fallbacks (see [Names and localization](#names-and-localization)).
- **Free text** in fields such as `notes`, `_comment`, `inspiration` and `look_source` is documentation for contributors, written in English (the broom notes in `shared/brooms.json` are still in Spanish until they are translated). Except where this file says otherwise, the game never displays it.

## Layout

```
data/
  shared/                     # data shared by every season pack
    brooms.json               # broom catalogue
    city_names.json           # club city names in the other 9 languages
    climate.json              # weather odds per region
    crest_templates.json      # SVG templates and shapes for generated crests
    grounds.json              # club ground capacities and landscape types
    map.json                  # GENERATED by tools/make_map.py, don't edit by hand
    regions.json              # regions and their countries
    schools.json              # magic schools
    names/<region>.json       # name tables for the filler generator
    rules/match_rules.json    # canon match rules
    rules/fouls.json          # canon foul catalogue
    rules/sim_params.json     # match-engine calibration
    generator/                # (empty, reserved)
  packs/<pack>/               # one folder per starting season; the only pack is 1993-94
    clubs/<club_id>.json
    players/<player_id>.json
    competitions/<comp_id>.json
    schools/<school_id>.json  # school houses and canon students
    national_teams.json
    events.json               # scripted events from the books
    world_cup_history.json
```

`SimLoader.load_all(pack)` reads everything under `shared/` plus one pack folder. It loads every `*.json` file in `clubs/`, `players/`, `competitions/`, `schools/` and `shared/names/`, so you add a record by dropping in a new file. Anything the pack doesn't supply (filler clubs, squads, youth players, schools without canon students) is generated deterministically at game start.

## Conventions

### `source` and canon markers

Every record has a `source` that says how faithful it is to the books:

| Value | Meaning |
|---|---|
| `canon_book` | The seven novels |
| `canon_qtta` | *Quidditch Through the Ages* |
| `canon_pottermore` | Pottermore / Wizarding World writing |
| `canon_dp` | J.K. Rowling's *Daily Prophet* Quidditch reports |
| `inferred` | Derived from canon but not stated outright |
| `filler` | Made up for the game (generic) |
| `filler_authored` | Made up for the game, but hand-designed (name, colours, emblem, style), e.g. most non-British clubs |

`canon_cards`, `prop` and `videogame` are also defined values (Chocolate Frog cards, film props, video games), but no current record uses them. Some records in `events.json`, `world_cup_history.json`, `rules/fouls.json` and the school `house_info` blocks give a chapter reference as their source instead (`"PoA 9"`, `"GoF 8"`).

Inside free-text `notes`, square-bracket tags mark where each fact comes from:

- `[inferred]`: derived from canon.
- `[FILLER]`: invented for the game.
- `[game]`: a game-design decision.
- Book references: `[PS]`, `[CoS]`, `[PoA]`, `[GoF]`, `[OotP]`, `[HBP]`, `[DH]`, `[QTTA c7]`, `[FB]`, `[DP]`, `[PM]`/`[Pottermore]`, `[Film Wizardry]`, `[Prop]`, `[Wiki]`.

Rule of thumb: stay as close to the books as possible. When you invent something, keep it minimal and tag it.

### Id prefixes

| Prefix | Entity |
|---|---|
| `club_` | Club (`club_puddlemere_united`) |
| `player_` | Pack player |
| `comp_` | Competition (`comp_british_irish_league`) |
| `school_` | School (`school_hogwarts`) |
| `student_` | Canon student in a school file |
| `hs_<school>_<house>` | School house team (`hs_hogwarts_gryffindor`) |
| `nt_<country_id>` | National team (`nt_bul`) |
| `broom_` | Broom model (`broom_nimbus_2000`) |

Countries use short ids (`eng`, `sco`, `wal`, `nir`, `irl`, `bul`, `ltu`…) defined in `shared/regions.json`.

### Names and localization

- Countries and regions have `name_es` and `name_en`. Competitions and national teams have `name` (Spanish, or the canon English name) and `name_en`.
- In the UI, `Loc.name()` first looks for a translation key in `locale/strings.csv` (`country.<id>`, `region.<id>`, `comp.<id>`, `house.<name>`) and only falls back to the data name if the key is missing. The fallback is `name_es` for countries and regions; for competitions it is `name_en` in English and `name` in every other language. **When you add a competition, country or region, add its key in all 10 languages** (see `tools/add_keys.py`).
- Club `city` is written in Spanish as `"City, Country"` (for example `"Hiroshima, Japón"`). In other languages, `Club.display_city()` swaps the city part for its name in the current language using `shared/city_names.json` and localizes the last comma-separated part through `country.<country_id>`. Cities missing from `city_names.json` appear as written.

### Attributes

Ratings use a 1-20 scale. Pack files store integers; the engine works with floats.

```
flying:    speed, acceleration, agility, broom_control, balance, altitude, dive
technical: passing, catching, shooting, dodging, stealing, interception,
           keeping, beating, beat_accuracy, snitch_catching
mental:    aggression, anticipation, bravery, composure, concentration, creativity,
           decisions, determination, flair, influence, off_ball, positioning,
           teamwork, work_rate
physical:  stamina, strength, natural_fitness, reflexes, eyesight
hidden:    consistency, big_matches, injury_proneness, dirtiness, versatility,
           adaptability, ambition, controversy, loyalty, pressure,
           professionalism, sportsmanship, temperament
```

Positions: `K` Keeper, `C` Chaser, `B` Beater, `S` Seeker.

## Pack files (`packs/<pack>/`)

### `clubs/<club_id>.json`

```json
{
  "id": "club_puddlemere_united",
  "name": "Puddlemere United",
  "short_name": "Puddlemere",
  "city": "Puddlemere (río Piddle), Dorset, Inglaterra",
  "country_id": "eng",
  "region_id": "british_isles",
  "founded": 1163,
  "colors": {"primary": "#1B2A4A", "secondary": "#C9A227"},
  "emblem_key": "crossed_bulrushes",
  "identity": {"style_tags": ["balanced", "reserve_team"], "motto": "", "rivalries": ["club_holyhead_harpies"],
               "fan_traits": ["anthem_beat_back_those_bludgers"], "mascot": ""},
  "league_id": "comp_british_irish_league",
  "level": 1,
  "reputation": 9100,
  "finances": {"balance": 15000, "wage_budget_weekly": 450, "transfer_budget": 4000},
  "facilities": {"training": 4, "medical": 4, "broom_workshop": 4},
  "constraints": {},
  "manager_name": "Philbert Deverill",
  "history": {"league_titles": 22, "european_cups": 2, "notes_keys": ["club.puddlemere.oldest", "club.puddlemere.anthem"]},
  "source": "canon_qtta",
  "notes": "Navy blue colors and golden bulrushes [QTTA c7]; ... Hex [inferred]. Finances [filler]."
}
```

- `level`: division within the league (1 = top; the pack has levels 1-3).
- `emblem_key`: the emblem on the club's crest (used by `tools/make_crests.py` and to pick a crest template). The game shows the first crest it finds for the club id: the AI-made crest in `assets/crests/ai/`, an official PNG the user keeps in their own copy (`assets/crests/<id>.png`, never shipped; see ATTRIBUTION.md), the embroidered patch in `assets/crests/patched/`, then the flat SVG made by `tools/make_crests.py`. Clubs with none of these (for example clubs created during the game) get a template from `shared/crest_templates.json`, picked by `emblem_key` or by a hash of the id; national teams (`nt_*`) get no template. Hand-designed clubs leave it empty and add `emblem_desc`, an English description of the intended figure (documentation only).
- `identity.style_tags`: free tags describing playing style (`balanced`, `attacking`, `flair`, `physical`…). `motto` is displayed on the club screen when set.
- `identity.rivalries`: club ids of the club's derby rivals, listed on both clubs (`src/game/rivalries.gd`: Prophet previews, +25 % gate, stronger morale and fan swings, an optional board objective "finish above the rival"). The British and Irish League keeps only the canon ones; the other leagues have invented ones, marked by `identity.rivalries_source: "filler"` and a notes line (table in `docs/design/07`).
- `constraints`: currently only `{"women_only": true}` (Holyhead Harpies), which restricts signings to female players.
- `history`: `league_titles`, `european_cups`, optional `european_cup_semifinals` and `last_league_title`, and `notes_keys` (translation keys for club history facts).
- `manager_name` may be empty; a name is then generated.

### `competitions/<comp_id>.json`

One file per regional league (20 in 1993-94). Cups, continental competitions and the World Cup are built by the engine from these.

```json
{
  "id": "comp_eastern_europe_league",
  "name": "Liga de Europa del Este",
  "name_en": "Eastern European League",
  "type": "league",
  "region_id": "eastern_europe",
  "country_ids": ["bul", "pol", "ltu", "rou", "mda", "tra", "rus"],
  "level": 1,
  "format": {"rounds": 2, "table": "points_scored",
             "tiebreak": ["points_conceded_asc", "snitch_catches_desc"],
             "time_cap_minutes": null, "knockout": null},
  "calendar": {"start_month": 9, "end_month": 6, "match_weekday_pool": ["fri", "sat", "mon"], "period_years": 1},
  "club_ids": ["club_vratsa_vultures", "club_grodzisk_goblins", "..."],
  "filler_clubs": 0,
  "venues": ["venue.balkan_mountains", "venue.biebrza_marshes", "..."],
  "prizes": {"galleons_champion": 5000, "galleons_per_position_step": 250, "awards": []},
  "source": "filler",
  "notes": "..."
}
```

- `club_ids`: the authored clubs. `filler_clubs`: how many generated clubs to add.
- `venues`: neutral venues as `venue.<key>` translation keys (defined in `locale/strings.csv` in all 10 languages). A plain name or a `{"name": ...}` object is also accepted and is displayed as written. League matches are played at the home club's ground. These venues are used for cup finals and continental competitions.
- Optional `trophy` (e.g. `"League Cup"`) and `founded`.
- Not read by the current engine (informational): `calendar.match_weekday_pool`, `calendar.period_years`, the `prizes` block (the engine uses its own prize defaults).

### `schools/<school_id>.json`

House colours and canon students for each school. The school list itself is in `shared/schools.json`.

```json
{
  "_comment": "...",
  "school_id": "school_hogwarts",
  "house_colors": {"Gryffindor": {"primary": "#7F0909", "secondary": "#D3A625"}, "...": {}},
  "venue": "Campo de Quidditch de Hogwarts",
  "students": [
    {"id": "student_harry_potter", "first_name": "Harry", "last_name": "Potter", "gender": "m",
     "house": "Gryffindor", "position": "S", "birth_date": "1980-07-31", "talent": 5,
     "broom": "broom_nimbus_2000", "nationality": "eng", "source": "canon_book", "notes": "...",
     "look": {"skin": "light", "hair": "black", "hair_style": "messy", "eyes": "green",
              "glasses": true, "scar": "lightning", "beard": false, "freckles": false}}
  ]
}
```

- `talent` (1-5) sets ability and potential. Optional fields: `captain`, `birth_date_estimated`, `positions_extra` (e.g. `{"C": 12}`), `joins_team` (`YYYY-MM-DD`: a canon student who first makes the house team in a later season, such as Ron and Ginny in 1995-96, is added at that season's rollover, not at world creation).
- Only Hogwarts has canon students; the other schools generate theirs.
- Schools with invented houses add `source` and a `house_info` block: `{"<House>": {"emblem_desc", "inspiration", "source"}}`. It documents the folklore behind each house and is not read by the game.
- `venue` is informational. The game names a school's pitch with the `venue.school` translation key.

### `national_teams.json`

```json
{"teams": [{"id": "nt_bul", "country_id": "bul", "name": "Bulgaria", "name_en": "Bulgaria",
            "tier": "elite", "mascot": "veelas",
            "colors": {"primary": "#C8102E", "secondary": "#FFFFFF"}, "world_cup_titles": 0,
            "canon_roster_1994": [{"first_name": "Viktor", "last_name": "Krum", "position": "S",
                                   "birth_date": "1976-04-01", "birth_date_estimated": true, "notes": "...", "look": {}}],
            "qualified_1994": true, "source": "canon_book", "notes": "..."}],
 "notes": "..."}
```

- 50 teams. `tier`: `elite | strong | mid | weak` (see `docs/design/07` §5.3).
- `qualified_1994`: the nine teams the books show at the 1994 World Cup finals.
- `canon_seven_until` (`YYYY-MM-DD`, optional): until that date the `canon_roster_1994` players are picked first for the national squad (Bulgaria and Ireland until the 1994 final [GoF 8]).
- Displayed names come from `country.<country_id>`. The `name` field and `mascot` are stored but not displayed.
- Every country with a national team must belong to a region in `shared/regions.json`, even a region without a league (for example the `middle_east` region, which has no `league_id`).

### `events.json`

Scripted events from the books that happen on a given date. `kind` is one of `fixture_result` (a fixed school match result), `wc_final`, `cup_champion`, `broom`, `graduate_to`, `captain`, `retire`, `no_school_cup`, `ban`, `position` (a canon change of position: `player_id`, `position`; Ginny to Chaser in 1996). Which other fields appear depends on the kind: `competition_prefix`, `home`, `away`, `score_home`, `score_away`, `snitch_team`, `catcher`, `catcher_last_name`, `duration_min`, `player_id`, `player_ids`, `model_id`, `club_id`, `squad`, `school_id`, `competition_id`, `champion`, `season`, `until`. Every event has `date`, `kind`, `source` and `notes`. Optional `news_key` (on `broom`, `captain`, `ban`, `retire`): a `news.book.*` locale key (headline, line break, body; `{player}`, `{house}`) published in the Daily Prophet and sent as an owl when the event touches the manager's house. The finalists of a `wc_final` win their earlier matches of that World Cup, so the written final is reached through the bracket.

### `world_cup_history.json`

`{"past": [{year, champion, runner_up, note, score?}], "future": [{year, champion, runner_up, score, source, catcher_last_name?}]}`. Champions and runners-up are country ids. Past finals go into the game's history and national-team titles. `future` is reference only and is not read; the canon finals played during a game are scripted as `wc_final` events in `events.json`.

## Shared files (`shared/`)

### `news_fillers/<publication>.json`

Filler items for the newspaper (`NewsGenerator.filler_item`), one file per publication (`prophet`, `quibbler`, `witch_weekly`, `which_broomstick`; the masthead key is `news.masthead.<publication>`, none for the Prophet's own column). Each file is an array of `{"key", "from", "to"?, "months"?, "source", "notes"}`. The item can appear from year `from` to year `to` (inclusive), only in `months` if given, so nothing runs ahead of the books' chronology. The same key may appear twice to gate a span that starts or ends mid-year. Text lives in the locale key (headline, `\n`, body).

### `regions.json`

```json
{"regions": [
  {"id": "british_isles", "name_es": "Islas Británicas", "name_en": "British Isles",
   "school_id": "school_hogwarts", "names_file": "british_isles", "league_id": "comp_british_irish_league",
   "countries": [{"id": "eng", "name_es": "Inglaterra", "name_en": "England",
                  "demonym_es": "inglés", "demonym_en": "English"}]}
 ],
 "notes": "..."}
```

23 regions with 69 countries. `middle_east`, `maghreb` and `indian_ocean` have no league; they exist so their national teams have a home.

### `schools.json`

```json
{"schools": [{"id": "school_hogwarts", "name": "Hogwarts School of Witchcraft and Wizardry", "short_name": "Hogwarts",
              "country_id": "sco", "region_ids": ["british_isles"],
              "houses": ["Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin"],
              "source": "canon_book", "houses_source": "...", "notes": "..."}]}
```

11 schools. `houses_source` is optional.

### `brooms.json`

```json
{"schema": "brooms/1", "scale_note": "...",
 "brooms": [{"id": "broom_oakshaft_79", "model": "Oakshaft 79", "manufacturer": "Elias Grimstone", "year": 1879,
             "speed": 7, "acceleration": 5, "turning": 4, "braking": 8, "altitude": 9, "stability": 15,
             "durability": 19, "degradation_per_season": 0.2, "price": 900,
             "available_from": 1879, "available_to": null, "scarcity": "common",
             "source": "canon_qtta", "notes": "..."}]}
```

`speed` through `stability` and `durability` (resistance to Bludgers and wear) are on the 1-20 scale. `degradation_per_season` is the speed/altitude lost per season. `available_to` is a year or `null` and `scarcity` is one of `common`, `uncommon`, `rare`, `very_rare`; neither is read by the current engine. `price` is in Galleons and is `[filler]` unless the notes say otherwise. Optional `professional`, default `true`. When `false` the broom is never on sale to clubs (`GameEngine._brooms_on_sale`). Only `broom_bluebottle` sets it. Broom `notes` are documentation; the tooltip in the encyclopedia's broom table comes from the `broom.notes.<id>` translation keys (10 languages).

### `names/<region>.json`

Name tables for generated players and clubs. Two formats exist:

- **Version 1** (`british_isles.json`, `argentina.json`) has its lists at the top level.
  `{"region_id", "first_names_m": [], "first_names_f": [], "last_names": [], "club_nouns": [], "cities": [], "notes"}`
- **Version 2** (all others, `"schema": 2`) has per-country lists.
  ```json
  {"region_id": "eastern_europe", "schema": 2, "club_nouns": ["Vultures", "..."], "club_nouns_lang": "en",
   "by_country": {"bul": {"first_names_m": ["..."], "first_names_f": ["..."], "last_names": ["..."], "cities": ["..."]},
                  "rus": {"...": [], "last_names_f": ["Ivanova", "..."]}},
   "notes": "..."}
  ```

The generator uses `by_country[country_id]` when present and falls back to the top-level lists otherwise. Some countries have no `cities` list. `last_names_f` is optional, for languages with feminine surnames. It pairs by index with `last_names` (`Ivanov` → `Ivanova`). Some `by_country` entries carry their own `notes`.

### `city_names.json`

`{"notes", "cities": {"<Spanish city name>": {"en", "de", "fr", "it", "pt_BR", "nl", "ru", "ja", "zh_CN"}}}`, e.g. `"Colonia": {"en": "Cologne", "de": "Köln", ...}`. Used for every non-Spanish locale; a missing language falls back to `en` (see [Names and localization](#names-and-localization)).

### `climate.json`

`{"notes", "default": {hemisphere, rain, snow}, "regions": {"<region_id>": {hemisphere, rain, snow}}}`. `hemisphere` is `N`, `S` or `T` (tropical). `rain` is the chance of rain per match; `snow` is the chance of snow in midwinter. The values are game-design filler.

### `grounds.json`

Club grounds (game-design filler; in the books professional Quidditch is played on remote moors). `capacity_by_level` gives `[min, max]` capacity per division. `neutral` gives capacities for neutral venues (`wc_knockout`, `wc_groups`, `cup`, `cont_knockout`, `cont_groups`, `national_cup`, `default`). `kinds_by_region` lists the landscape types (`moor`, `heath`, `steppe`…) used to name grounds through the `ground.kind.<kind>` translation keys.

### `crest_templates.json`

Generated crests. `templates` maps a template key to an SVG drawn in placeholder colours; `tokens` (`p` primary, `s` secondary, `dp` dark primary, `tl`/`td` light/dark thread) lists the placeholder hex values the game replaces with club colours, and `dark_factor` sets how much `dp` darkens. `template_shapes` maps each template to an outline in `shapes` (SVG paths on a `size` = 128×148 canvas). `pack_shapes` gives the outline of each authored club's own SVG crest (used by `tools/patch_crests.gd`).

### `map.json`

Generated by `tools/make_map.py`. It holds the projection of the world and Europe maps on the New Game screen, plus the normalized pin position of each league and school. Edit `PINS` in the script and re-run it; don't edit this file.

### `rules/`

- `match_rules.json`: canon match rules (10 points per goal, 150 for the Snitch, no substitutions, timeouts, night pauses in long matches, forfeits…). One flat object.
- `fouls.json`: an array of `{id, who, sanction, source, example, note?}`. `who` is one of `any`, `keeper`, `chaser`, `beater`, `non_seeker`; `sanction` is one of `penalty`, `penalty_if_intentional`, `penalty_or_send_off`, `stop_play_penalty`, `goal_annulled`, `goal_stands`, `forfeit`. The encyclopedia shows the catalogue through translation keys.
- `sim_params.json`: match-engine calibration, grouped as `condition`, `consistency`, `quaffle`, `bludgers`, `fouls`, `snitch`, `timeouts`, `mutual_end`, `hard_cap_hours`. Tune them with `tools/sim_batch.gd` (see `docs/design/03` §4).
